# Ravi Rajendran — Professional Portfolio

This package contains a responsive, professional one-page portfolio website tailored to Ravi Rajendran's IT & Data Analyst / Government Projects profile.

## Files
- `index.html` — complete responsive website
- `favicon.svg` — lightweight browser icon
- `Ravi_Rajendran_Resume_SPC_SectorExpert_Enhanced_Technical_Skills.docx` — tailored resume download

## Publish on GitHub Pages
1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload all files in this package to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Select the repository branch/root as the publishing source.
5. Your site will be available at `https://YOURUSERNAME.github.io/`.

## Before publishing
- Replace the GitHub username with your actual username when creating the repository.
- Review the contact details and resume filename.
- If you later have LinkedIn, GitHub or Power BI portfolio links, add them to the Contact/Projects section.
- The website deliberately avoids unsupported claims and uses the project/experience information supplied in the resume.
